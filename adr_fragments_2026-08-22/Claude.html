# **6. Weekly Telegram Digest**
176
 
177
The weekly digest is an automated Phase 1 task. It runs inside the openclaw_fastapi container as a scheduled asyncio task, fires every Sunday at 08:00 local time, and sends a single formatted Telegram message to the operator chat. It requires no manual action.
178
 
179
## **6.1 Implementation**
180
 
181
The digest task is added to main.py alongside the existing heartbeat loop. On startup, an asyncio task calculates seconds until the next Sunday 08:00 and sleeps until that time, then fires weekly thereafter. The task queries agent_actions and security_events (ADR-038) directly via the existing PostgreSQL pool.
182
 
183

## **6.3 Real-Time Alerts**
205
 
206
The following events send an immediate Telegram alert regardless of the weekly digest schedule. These are not batched — they fire at the moment of detection via the interceptor or security scanner.
207
 
208
- Prompt injection attempt detected — fires immediately, includes persona, session ID, input snippet (first 100 chars)
209
 
210
- Opus (Tier 4) usage — fires immediately with session ID and cost estimate
211
 
212
- Unauthorized user ID attempt — fires immediately with user ID and channel
213
 
214
- Blocked request spike — 5 or more blocked requests from the same channel_id within 60 minutes
215
 
216
- p95 response time exceeds 300 seconds for any 1-hour rolling window — fires once per hour maximum
