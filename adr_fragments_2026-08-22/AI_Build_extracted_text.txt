## PROJECT IDENTITY

Product: OpenClaw (working name) — a multi-tenant SaaS platform providing AI-assisted SNAP compliance decision support for state agencies.
Owner: Sheldon — non-coder, domain expert, former PC subcontractor background working on IBM and related desktop, software, and network environments. Currently working from Mac Mini M1 prototype environment and web-based Claude.ai.

Stage: Pre-prototype strategic planning phase. No code written yet.

## CORE DESIGN PRINCIPLE

OpenClaw is a decision support tool — not a database or case management system. This principle governs every agent and assistant without exception.

Sheldon brings data to OpenClaw. OpenClaw analyzes and drafts. Sheldon takes the output away. OpenClaw does not retain session data, case information, or findings between sessions. No PII is stored. The platform is stateless.

When helping design any component, always ask: does this require stored data to be useful? If yes, it is a database function — not an OpenClaw function.

## AGENT ARCHITECTURE

Four full agents:

Eligibility Agent
- Primary users: Eligibility caseworkers, supervisors
- Primary authority: Food and Nutrition Act (as amended by OBBB), 7 CFR Part 273, state statute, state manual, active waivers
- Function: Policy lookups, rule application, income/deduction guidance, waiver-aware responses, statutory-CFR gap flagging

QC Agent
- Primary users: QC analysts, federal reviewers
- Primary authority: 7 CFR Part 275, FNS Handbook 310, Food and Nutrition Act (OBBB provisions), 7 CFR Part 273
- Function: Error classification, CFR citation, deficiency documentation, temporal accuracy for sample month, statutory-CFR gap flagging
- Independent of QA Agent

QA Agent
- Primary users: QA team staff only
- Primary authority: State QA policy (per-tenant, primary), 7 CFR Part 273, FNS PER research, state manual, active waivers
- Function: Case selection methodology support, review instrument generation, error identification and classification, findings documentation, corrective action recommendations
- Independent of QC Agent — different primary authority, different methodology, different purpose
- Does NOT use 7 CFR 275 methodology
- All functions are session-based only — no trend analysis, no management feedback, no training tracking

State Manager / Analytics Agent
- Primary users: State program managers
- Function: Analysis of data uploaded in current session, management report drafting — no persistent dashboard, no cross-session aggregation

Two document support assistants (toe-in-the-water — validates market interest for Phase 2 full products):

Hearings Preparation Assistant
- Primary users: Eligibility workers assigned as agency hearings representative
- Primary authority: 7 CFR 273.15 (procedural), state hearing rules, state statute, 7 CFR Part 273 (substantive basis)
- Scope: Pre-hearing only, SNAP only
- Critical distinction: Supports the STATE AGENCY REPRESENTATIVE — not the Hearings Officer (independent neutral adjudicator). In Maine, well-trained eligibility workers represent the Department at hearings and are assigned to cases other than their own (conflict of interest policy).
- Functions: Position drafting, citation retrieval, appellant grounds review, informal resolution contact drafting with hearing rights guardrails

Overpayments Preparation Assistant
- Primary users: Eligibility workers, Program Integrity / QA staff
- Primary authority: 7 CFR 273.18 (claims), 7 CFR 273.16 (IPV), state statute, state collection rules
- Scope: Claim establishment and demand notice only, SNAP only, all three claim types (AE, IHE, IPV)
- Does NOT include: tracking, aging, referrals, FNS-209 reporting (all require archived data — deferred to Phase 2)

## TEN-LAYER KNOWLEDGE BASE

Layer 1 — Federal Authorizing Statute: Food and Nutrition Act of 2008 (7 U.S.C. 2011 et seq.) as amended. Source: uscode.house.gov. Shared — all agents.
Layer 2 — Federal Statutory Modifications: HR1/OBBB (eff. 7/4/2025), PRWORA, Farm Bill provisions, Fiscal Responsibility Act 2023. Source: congress.gov, FNS implementation memos. Shared — all agents.
Layer 3 — Federal CFR: 7 CFR Part 273, 275, 273.15, 273.18. Source: ecfr.gov. Shared — all agents.
Layer 4 — FNS Policy and Guidance: FNS Handbook 310, COLA memos, policy memos, FNS PER research, OBBB implementation memos. Source: fns.usda.gov. Shared — all agents.
Layer 5 — State Statute: State SNAP-related statutes where applicable. Source: State legislature websites. Per-tenant. Eligibility, QA, Hearings Prep.
Layer 6 — State Manual: Published state SNAP policy manual. Pre-populated from public sources plus state admin uploads. Per-tenant. Eligibility, QA, Hearings Prep, Overpayments Prep.
Layer 7 — Waiver Registry: FNS-approved waivers, ABAWD waivers, demonstration projects with expiration dates and CFR sections modified. Per-tenant. Eligibility, QC, QA.
Layer 8 — Configuration: SUAs, income limits, asset limits. Updated annually October. Per-tenant. Eligibility, QC, QA.
Layer 9 — State QA Policy: State QA program policy, review methodology, sampling procedures. Per-tenant. QA Agent only — primary authority.
Layer 10 — State Hearing / Collection Rules: State fair hearing procedures, state collection laws, statute of limitations. Per-tenant. Hearings Prep, Overpayments Prep.

## FIVE-STEP COMPOUND CITATION ENGINE

Step 1: Check federal authorizing statute (Food and Nutrition Act as amended). Identify statutory basis.
Step 2: Check federal statutory modifications (OBBB, PRWORA, FRA 2023). Flag if statutory change post-dates CFR. Statute controls where conflict exists.
Step 3: Retrieve federal CFR baseline. Note if CFR predates applicable statutory change and flag to worker.
Step 4: Check active state waivers modifying relevant CFR sections.
Step 5: Retrieve state manual and state statute where applicable. Construct compound answer with all layers displayed and linked.

## OBBB FLAGGING REQUIREMENT — CRITICAL

HR1/OBBB became effective 7/4/2025. CFR has not been fully updated. When retrieving on OBBB-affected topics, agents must: (1) surface the statutory provision first, (2) note whether CFR has been updated, (3) cite statute as controlling if CFR predates the change, (4) flag to worker and direct to current FNS implementation memos.

OBBB-affected topics: noncitizen eligibility (Section 10108), work requirements / ABAWD changes, state cost sharing for PER over 6%, categorical eligibility modifications, benefit calculation changes.

Temporal accuracy for OBBB: OBBB provisions effective 7/4/2025 are not applied to reviews of cases certified before that date.

## RAG AND CITATION RULES — CRITICAL

- Citations may ONLY come from retrieved source documents at any layer — statute, CFR, state rule, or waiver. Never from model memory.
-Never assert the status of any legislation from model memory — including whether a bill has been enacted, its effective date, which provisions are in effect, or whether implementing regulations have been issued. All legislative status assertions must be retrieved from congress.gov or a verified source before the assertion is made. Training data is unreliable for current legislative status. This rule applies to OBBB, Farm Bill reauthorization, and any other federal or state legislation relevant to platform function.
- Every citation must display the retrieved source text and a verification link.
- Statute retrieved before CFR. Statutory-CFR gaps flagged explicitly.
- QC agent queries temporally accurate — rule in effect on sample month date, including statutory effective dates.
- QA agent queries temporally accurate — rule in effect at certification date being reviewed.
- When a waiver does not exist for a state, system must correctly return no waiver rather than hallucinating one.
- State statute, state manual, and waiver citations held to identical standard as CFR citations — never from memory.

## CONTENT RESPONSIBILITY MODEL

Tier 1 (platform maintains): Layers 1-4 — federal statute, statutory modifications, CFR, FNS guidance.
Tier 2 (state maintains): Layers 5-10 — state statute, state manual, waiver registry, configuration, QA policy, hearing/collection rules.
Pre-population of public content is a key sales differentiator.

## DATA PRIVACY AND COMPLIANCE POSTURE

- No PII — design constraint enforced at architecture level. Stateless sessions. No case-level data retained.
- FedRAMP NOT required (no PII, no federal data processing trigger).
- SOC 2 Type II deferred until post-revenue. Near-term: vendor security questionnaire plus DPA plus data flow diagram.
- Product positioned as AI-assisted research and drafting tool requiring human verification — not autonomous authority.

## DOWNSTREAM SUITE — DEFERRED TO PHASE 2

Full Hearings Representative (before, during, after) and Full Overpayments Module (tracking, referrals, FNS-209) explicitly deferred. Both are downstream consequences of eligibility and QC decisions. Do not scope these into Phase 1.

## PROTOTYPE VALIDATION TESTS (10 TOTAL)

Test 1: Maine manual citation accuracy — no hallucinated citations.
Test 2: Maine BBCE compound citation — all five layers correct.
Test 3: QC temporal accuracy — correct version for specified sample month.
Test 4: NH no-waiver response — system does not hallucinate waivers.
Test 5: OBBB statutory flagging — statutory provision surfaced; CFR gap flagged; FNS memo directed.
Test 6: Statutory hierarchy — statute cited as controlling where statute and CFR differ post-OBBB.
Test 7: QA Agent independence — different primary authority cited than QC Agent for same question.
Test 8: Hearings Prep citation and rights — 7 CFR 273.15 retrieved; hearing rights preserved in informal resolution draft.
Test 9: Overpayments claim classification — correct AE/IHE/IPV classification and correct 7 CFR 273.18 subsections.
Test 10: Decision support boundary — agents decline requests to store or track data across sessions.

Phase 2 (6-18 months): AWS GovCloud plus Bedrock, pilot agreement with 1-2 states, full Hearings and Overpayments products if market validates.

## HOW TO HELP IN THIS PROJECT

- When helping design system prompts: enforce citation grounding rules, five-step retrieval, OBBB flagging, and decision support principle.
- When helping with document collection: start with federal statutory layers (Food and Nutrition Act, OBBB provisions) before CFR.
- When helping with RAG architecture: account for ten knowledge base layers, five-step compound citation, temporal accuracy including statutory effective dates.
- When helping with QA Agent: maintain strict independence from QC methodology; state QA policy is primary authority; all functions must be stateless.
- When helping with Hearings Prep: maintain agency representative framing; always include hearing rights guardrails in drafted communications.
- When helping with Overpayments Prep: enforce AE/IHE/IPV classification discipline; 7 CFR 273.18 subsection accuracy is critical.
- When generating test questions: include adversarial cases targeting hallucinated citations, fabricated waivers, OBBB gaps, and inappropriate data storage requests.
- Always flag if a suggestion would require archived data, persistent storage, or PII — these are database functions, not OpenClaw functions.
- Sheldon has deep regulatory expertise — do not over-explain CFR basics, but do flag statutory-CFR gaps and OBBB implications proactively.
